      How this was built

      The pipeline was run eight ways on 300.tiff with a profiler hook that records every call between repo functions, with its full chain of callers: midog --ann-id 14499 with the gray gate, the hematoxylin gate plus chromatin_od, and no gate; midog random draw; click 1411 3551; click 6410 250 (template unreadable); box 1391 3531 41 41; box 6050 3415 41 41 (gate refused).

      Dataclass constructors run generated code the hook cannot see, so FSConfig and Augmentation were added from the source, as were the three calls that never run here. A static scan of every function in the tree found no other call to a repo function. Committed code: c8da799.
