# Environment for `midog_utils/` and `find_and_suppress_midog.ipynb`.

# This is NOT requirements.txt. That file pins the fastai/SlideRunner training stack for
# the MIDOG++ reference pipeline; `midog_utils` deliberately imports none of it, so the
# two environments are separate and this one is much smaller.
#
# The pin that actually matters is **numpy < 2**. The opencv wheel in use was built
# against the numpy 1.x C API, so under numpy 2.x `import cv2` fails with
# `AttributeError: _ARRAY_API not found`, and `tifffile`'s LZW path -- needed to read the
# pyramidal 505.tiff / 506.tiff -- fails the same way through `imagecodecs`. Either hold
# numpy below 2 or install an opencv wheel built for numpy 2; do not mix.
#
# Verified working on Python 3.11.5 (an Anaconda install), which is the interpreter the
# notebook's recorded outputs were produced with. Check yours with:
#     python -c "import numpy, cv2; print(numpy.__version__, cv2.__version__)"
